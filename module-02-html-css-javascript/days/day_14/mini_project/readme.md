# Day 14 Mini Project - Ethio Telecom Web Layout

## Overview
This project is a responsive web layout created for **Ethio Telecom** as part of the Day 14 coursework. It showcases the implementation of modern CSS Grid techniques to structure a complete multi-section webpage.

---

## Features & Layout Components

1. **Header Area:**
   - Features the official brand logo.
   - Includes horizontal navigation links (`Home`, `Services`, `About`, `Contact`).

2. **Sidebar:**
   - Houses quick links for user navigation (Telebirr, Internet Packages, Voice Offers, Customer Support).

3. **Hero Section:**
   - Highlights the main banner image with a sleek gradient overlay and descriptive text overlay.

4. **Services Section (CSS Grid):**
   - Displays a multi-card grid using `repeat(auto-fill, minmax(...))` for clean, responsive card behavior.
   - Highlights core services: Mobile Data & Voice, Fixed Broadband, and Telebirr Digital Services.

5. **Footer:**
   - Displays copyright and project completion information.
