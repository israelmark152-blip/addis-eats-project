3. Specificity Explanation

Specificity Scores:

  • p (Element selector) = (0, 0, 0, 1)[cite: 6]
  • .note (Class selector) = (0, 0, 1, 0)[cite: 6]
  • #lead (ID selector) = (0, 1, 0, 0)[cite: 6]

Winner: #lead wins and renders green because the ID column has the highest score[cite: 6].
